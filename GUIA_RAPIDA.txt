🛠️  COMANDOS ÚTILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ver estado de servicios:
  $ docker-compose ps

  Ver logs:
  $ docker-compose logs -f backend
  $ docker-compose logs -f db

  Acceder a la base de datos:
  $ docker exec -it geoinformatica-db psql -U postgres -d inmobiliaria_db

  Verificar datos cargados:
  $ docker exec geoinformatica-db psql -U postgres -d inmobiliaria_db -c "
    SELECT 'comunas' as tabla, COUNT(*) as registros FROM comunas
    UNION ALL
    SELECT 'propiedades', COUNT(*) FROM propiedades
    UNION ALL
    SELECT 'grilla_espacial', COUNT(*) FROM grilla_espacial;"

  Reiniciar todo:
  $ docker-compose restart

  Detener servicios:
  $ docker-compose down

  Detener y eliminar datos:
  $ docker-compose down -v

🐛 SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❌ Puerto ocupado:
     • Cambiar puertos en docker-compose.yml
     • Ejemplo: "5433:5432" en lugar de "5432:5432"

  ❌ Base de datos no conecta:
     • Esperar 10 segundos: sleep 10
     • Verificar: docker exec geoinformatica-db pg_isready -U postgres
     • Reiniciar: docker-compose restart backend

  ❌ Scripts no encontrados:
     • Copiar nuevamente: ./cargar_datos.sh
     • O copiar manualmente (ver README_DESPLIEGUE.md)

  ❌ Datos no cargan:
     • Limpiar todo: docker-compose down -v
     • Reiniciar: docker-compose up -d
     • Re-ejecutar: ./cargar_datos.sh
